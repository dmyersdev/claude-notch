# V3 spike: from a fun side project to the notch app worth installing

**Question this spike answers:** what would make Claude Notch the one people pick, and recommend, in a crowded field? And what do we need to find out before committing to it?

**Short answer:** stop competing on features, where a dozen apps already overlap, and win on three things nobody else combines: **it's trustworthy** (signed, updates itself, nearly free on battery), **it's the best place to *finish* agent work** (review, steer, launch), and **it has a character people love**. V3 is mostly about the first; the other two are where we already lead.

## Where we stand

**What we already do well** (v2.0):
- Answering from the notch: Allow, Deny, Always, and Claude's multiple-choice questions.
- Review handoff: Claude's last message, per-file diffs, the test result, and Open PR.
- Session discovery that doesn't depend on hooks alone (the session registry), plus tucking idle sessions away.
- A real character system: props, stickers, parcels, wilting flags, high-fives, puffs. Most competitors show a coloured dot.
- 119 tests and a pure, tested simulation.

**Where we're behind** (measured or checked on 2026-10-16):

| Gap | Today | Why it matters |
|---|---|---|
| Battery and CPU | **~15% CPU, ~400 idle wakeups/s** with 3 sessions (sampled with `ps` and `top`) | The roundup reviewers judge "footprint" directly. A menu bar app should sit under 1% when nothing is happening. |
| Trust | Ad-hoc signed, not notarized, no auto-update. Friends must click Open Anyway, and permissions reset on every update | Feels unfinished. Updates are a chore, so people stay on old versions. |
| Name and character | "Claude Notch" collides with an existing **ClaudeNotch** and a **NotchClaude**. The sprite is Anthropic's mascot | Can't be found or distributed widely as-is. |
| Agents | Claude Code only | The leader (Vibe Island, paid) covers 30 agents. Open Island, Notchcode and Claude Statistics cover Codex and Gemini. |
| Terminals | Terminal, iTerm, editors, Claude app | No Ghostty, Warp, kitty, WezTerm, or tmux panes, which heavy users run. |
| Usage limits | Cost and context, but no plan limits (5-hour and weekly) | Several competitors show limits before you hit them. |
| Memory | Timelines and review state vanish when the app restarts | You lose the story of a session on every update or reboot. |
| Steering | No reply or stop (planned for v2.2) | Notchi and others do quick replies. |
| Phone | None | Only CodeIsland covers phone and watch. Leaving the desk is when you most need to know a session is blocked. |

## What "premium" means for us: six pillars

### 1. Trustworthy to install and keep
- **Developer ID signing and notarization** in a GitHub Actions release workflow: tag → build → sign → notarize → staple → zip and DMG → release. No more Open Anyway, and permissions survive updates. Needs the $99/year Apple Developer Program; the certificate and notary key go into repository secrets.
- **Auto-update with [Sparkle](https://sparkle-project.org)**: an appcast feed (an RSS file listing versions) generated by the release workflow and served from GitHub Releases or Pages. Updates are signed with an EdDSA key.
- **Homebrew cask:** `brew install --cask <name>`. Needs a public repo, or a separate public tap that points at public release assets.
- **Crash reporting the private way:** opt-in, local crash logs the user can attach to an issue. No analytics.

### 2. Nearly free on battery
Target: **under 1% CPU and fewer than 20 wakeups/s when nothing is changing**; under 5% while Claudes walk.
- **Draw only when something moves:** pause the stage's `TimelineView` when every Claude is resting, waiting or tucked away. Run at 15 fps for walking (pixel art doesn't need 30).
- **Stop polling the pointer 20 times a second:** use a global mouse-moved monitor, gated to the notch's screen region, and a tracking area while open.
- **Sleep with the screen:** stop all animation when the display sleeps, the screen is locked, or the notch is on a hidden Space.
- **Batch file work:** read the registry and transcripts on file-system events (`DispatchSource` and FSEvents) instead of every 3 s.
- A **performance test** in CI that fails if idle CPU regresses (the stage's frame cost, measured headlessly).

### 3. Covers how people actually work
- **Agents:** adapters behind one event model (`HookEvent` already is that model). Order: Codex CLI, Gemini CLI, then OpenCode, Cursor CLI and Amp. Each needs a spike on its hook or notification mechanism (below). Every agent gets its own original critter (the "cousins" from the V2 plan).
- **Terminals:** jump to Ghostty, Warp, kitty and WezTerm (each has its own scripting or IPC: kitty `@ focus-window`, WezTerm `cli activate-pane`, Ghostty and Warp need a spike), and tmux panes through `tmux select-pane` using the pane recorded in the session registry.
- **SSH and remote sessions:** an optional relay for sessions on another machine, forwarding the same hook events over an SSH tunnel.

### 4. The best place to finish agent work (our moat)
Ship the rest of the V2 plan, then go further:
- **v2.1 / v2.2 items:** task launcher with templates and worktrees, plan limits, alerts, ledger and weekly recap, reply and stop (by keystroke, per the spikes), guardrails and an audit log.
- **Deny with a reason:** a text field on Deny that becomes the hook's `message`, so Claude knows why and adjusts.
- **Spend caps:** per session or per day. At the cap, the notch asks before the next tool call (through the permission hook).
- **Review that actually reviews:** syntax-highlighted diffs, "approve and commit", "send back with a note" (by keystroke), and a combined review queue across sessions.
- **History that survives restarts:** timelines, reviews and the ledger saved to disk, with a searchable "what did my agents do today" view.

### 5. Reaches you away from the desk
- **Phone notifications first, no app needed:** when a session has been blocked for N minutes and the Mac is idle or locked, send a push through [ntfy](https://ntfy.sh) or Pushover with the user's own topic or key. It's cheap, private and opt-in.
- **Later:** an iPhone companion with Live Activities and Allow/Deny behind Face ID, synced through the user's private iCloud. Big and App Store-bound; only if the rest lands.

### 6. A character people love, as the brand
- **A new name and an original character** designed for this app: a distinct silhouette, a palette that isn't Anthropic's orange, and an app icon. The walking, props and moods carry over, since the system is sprite-agnostic.
- **Personality that rewards use:** achievements ("100 approvals", "first all-green week") unlock outfits; seasonal outfits; each agent gets a cousin critter.
- **Sound design:** a small set of soft, distinct sounds (blocked, finished, answered), off by default.
- **The weekly yearbook** (planned delight 9) as a shareable image. It's the growth loop: people post their agents' week.

## Business model

| Option | For | Against |
|---|---|---|
| **Free and open source** (today) | Goodwill, contributions, simplest | No funding for the $99/yr certificate or design work |
| **Free core, paid "Pro"** one-time (~$15–25) | Funds signing and design; the leader proved people pay | Licensing code, two editions to maintain |
| **Open source, with GitHub Sponsors** | Keeps it simple; signed builds as a thank-you | Unpredictable |

**Recommendation:** stay free and open source, and add GitHub Sponsors, for v3.0. Revisit Pro only if usage proves out; the natural Pro features are phone push, spend caps and remote sessions.

## Milestones (proposed)

- **v3.0 "Trust":** new name and character (S1), notarized and auto-updating releases (S2, S3), footprint under 1% idle (S4), history across restarts (S8), Homebrew. *The release that's worth recommending.*
- **v3.1 "Everywhere":** Codex and Gemini CLI (S5), more terminals and tmux (S6), phone push (S7), plan limits.

## How we'll know it worked
- Idle CPU under 1%, and under 20 wakeups/s.
- From download to the first Claude walking in under 60 seconds, with no Open Anyway step.
- Zero crashes reported across a release.
- People keep it installed: updates adopted within a week, issues from people we don't know, stars.
